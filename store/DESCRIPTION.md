**把 QQ 音乐的歌词搬到 Flexbar 上**

## 功能

- **正在播放**：专辑封面、歌名、歌手 · 专辑、进度条与时间；可开启"封面主色"动态背景
- **歌词**：QQ 音乐官方逐字歌词（QRC），字/词级高亮，支持翻译与日文罗马音；点一下歌词键即可切换单行 / 双行
- **播放控制**：播放/暂停、上一首、下一首 —— 走系统媒体键，不抢窗口焦点、不需要窗口自动化
- **状态键**：显示当前的播放检测方式与歌词来源，点击可强制重新加载歌词
- **设置页**：检测方式、歌词偏移微调、字体覆盖、一键诊断（含环境体检）

## 平台

- **Windows 10+**：读取系统媒体会话（SMTC）获取精确播放进度与播放/暂停状态，自动跟随切歌
- **macOS 10.15+**：优先使用 `nowplaying-cli`（`brew install nowplaying-cli`），并内置 MediaRemote 脚本与窗口标题兜底

## 说明

- 不需要登录 QQ 音乐账号，也不需要任何 API Key
- 歌词与封面来自 QQ 音乐公开接口，需要联网
- 安装包已内置渲染依赖（Windows / macOS Intel / Apple Silicon），安装后无需额外 `npm install`
- 按键：正在播放(600) · 歌词(480) · 播放暂停 · 上一首 · 下一首 · 状态(240)
